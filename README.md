# موقع Cabina Medical التعريفي

صفحة تعريفية متجاوبة لشركة Cabina Medical، تدعم العربية والإنجليزية مع ضبط اتجاه العرض تلقائيًا (RTL للعربية وLTR للإنجليزية). تستخدم الهوية الزرقاء والبيضاء وصورة الشركة المرسلة كخلفية للواجهة الرئيسية.

تتضمن الصفحة المعلومات الواردة في ملف الشركة: مستلزمات المعامل والزجاجيات والأجهزة المخبرية، والمواد الكيميائية والبيوكيميائية، ومنتجات الميكروبيولوجيا والأوساط الزرعية والمسحات، ومؤشرات مراقبة التعقيم. وتشمل بيانات التواصل أرقام الهواتف والبريد والعنوان والموقع الإلكتروني المنشور في الملف.

يتيح زر «تواصل معنا» اختيار الإرسال عبر البريد الإلكتروني أو واتساب. البريد هو `cabinamedical@gmail.com`، ورقم واتساب الذي أكده المستخدم مضبوط بصيغته الدولية `201222299957` في المتغير `WHATSAPP_NUMBER` داخل `index.html`. إذا تغيّر الرقم، حدّث هذا المتغير؛ ويُنشأ رابط `wa.me` تلقائيًا. يعرض قسم التواصل أيضًا روابط الشركة على Facebook وموقعها المرسل على خرائط Google.

تظهر المقدمة والعناصر أثناء التمرير بحركة خفيفة، مع رموز طبية متحركة في خلفية الـhero. تُخفى الحركات عند تفعيل إعداد تقليل الحركة في الجهاز.

يعرض قسم المنتجات ست بطاقات مصورة لمجالات التوريد: الزجاجيات والأجهزة، والمواد الكيميائية والبيوكيميائية، والاختبارات والمنتجات الميكروبيولوجية، والأوساط الزرعية، ومؤشرات مراقبة التعقيم، والمسحات ومستهلكات المعمل. الصور مأخوذة من صفحات الكتالوج المرفقة، ولكل بطاقة رابط للاستفسار في قسم التواصل. تتضمن الأمثلة المذكورة بالكتالوج الماصات والسحاحات والدوارق، والمذيبات والأصباغ، والسلالات المرجعية وكِتات الأحياء الجزيئية، والأوساط الجاهزة والإضافات المعقمة، ومسحات النقل وأطباق بتري ومستلزمات الأوتوكلاف.

افتح `index.html` في المتصفح لمعاينة الصفحة. تحميل Tailwind CSS وخط Cairo يتطلب اتصالًا بالإنترنت. لا يتضمن الموقع حجزًا أو تشخيصًا طبيًا.
